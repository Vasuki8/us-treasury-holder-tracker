Source Health

Every source is checked daily. If one feed fails, the tracker keeps the last valid observation and flags the source.

Important: “Daily updated” means the website checks official sources every day. Treasury-holder datasets publish on different schedules. Every section displays the latest available observation date rather than presenting stale data as today's holdings.
